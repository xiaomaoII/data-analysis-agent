# 后续扩展（尚未实现）

1. **Memory**：基于已确认任务继续追问，必须绑定数据版本、指标版本及会话身份；不能让旧口径污染新报告。
2. **Evaluation**：扩大保留题集，加入新的表达、SQL复杂度、人工业务评分；分开记录模型版本与工程约束带来的正确性。
3. **ML**：仅调用已经完成训练和验收的模型。首个业务方向是未来七天礼物价值，不称长期LTV；接口要求明确模型版本，保持项目二最终测试保护。
4. **A/B建议**：接收已经形成的报告和设计输入，输出目标人群、干预、对照、随机化单位、主要及护栏指标；缺少基线、MDE、功效参数时不编造样本量或周期。
5. **数据库与部署**：增加 PostgreSQL 适配器，再设计鉴权、资源隔离、任务队列和发布流程；当前本机应用不能直接作为公网服务。

Python 协议接口位于 extensions.py；它们只定义扩展边界，不是已实现功能。MVP 不包含文档向量库、PDF问答、任意Python执行、多用户权限或多Agent团队。
